# TrafoDNA V3.2 locked-final evidence package

This directory preserves the read-only evidence package produced after the
one-time V3.2 final evaluation. Its contents are copied from the archived
`V32_FINAL_REPORT_PACKAGE.zip` without model fitting, final-row generation,
or post-final tuning.

Archive SHA-256:

```text
422224935c18585356f2217ebb726b0ad1874c196c65c2cc5f36474a9ef53a4e
```

The package records a preregistered numerical result of **SUPPORTED (10/10
gates)** on 64 virtual cores and final scenarios 215--218. It is numerical
feasibility evidence only, not physical transformer validation, proof of
independent 64-bit entropy, or cryptographic security validation.

`V32_FINAL_REPORT.html` is Word-readable. Keep it with the `figures/`
directory when opening it outside GitHub. The source reporter, which validates
the frozen contract and hashes its locked inputs without generating new data,
is documented in [`docs/V32_FINAL_REPORTING.md`](../docs/V32_FINAL_REPORTING.md).
